# AppleTvSamsung
larp version of apple tv for samsung tvs

Прототип главного экрана для Samsung Smart TV на Tizen 6.0. На первом экране шесть плиток, при нажатии «Вниз» открывается список приложений телевизора.

Откройте `index.html` в браузере для просмотра интерфейса. На пульте работают стрелки, OK и «Назад». В Tizen Studio создайте TV Web Project с профилем `tv-samsung`, скопируйте в него HTML, CSS, JS и `config.xml` из репозитория и запустите проект на подключённом устройстве с профилем подписи Samsung.

Фон и внешний вид первых шести плиток берутся из [кадра «Sugar» из руководства Apple](https://support.apple.com/en-lb/guide/tv/atvb87e1c725/tvos). Изображение загружается с сервера Apple. При недоступности изображения доступен запасной экран с теми же кнопками. Плитки запускают подходящие приложения, установленные на телевизоре, если Tizen разрешает их открыть.
